# Capstone Projects, Alumni Archive, and Hall of Fame

These are core long-term archive features and are planned for Phase 7.

## 1. Capstone Projects
A dedicated section for completed and approved capstone projects, distinct from the general game library.

### Suggested fields
- Project title and abstract.
- Team members and contribution roles.
- Adviser name only if approved for public display.
- Academic year and program context.
- Project category/type.
- Technologies and tools.
- Demo/game link.
- Trailer/screenshots.
- Public documentation or publication link.
- Project status (in development, completed, archived).
- Approval and publication metadata.

### Rules
- Do not publish confidential, embargoed, or unpublished research materials.
- Obtain consent for names, images, and external documents.
- Capstone can link to a game record where the capstone produced a game.
- Preserve historical metadata when a team member graduates.

## 2. Alumni Archive
When a student graduates, an authorized administrator may update the profile to alumni after the graduation verification process is defined.

### Expected behavior
- Preserve published profile and portfolio according to visibility settings.
- Preserve game credits, capstone credits, and awards.
- Remove student-only permissions by default.
- Do not automatically delete accounts because institutional email access expires.
- Provide an account recovery/contact update path using a verified alternative email if approved.
- Alumni should be able to request profile corrections or privacy changes.

### Verification
**TBD:** define who verifies graduation and what evidence is acceptable. Do not automatically infer graduation from year level or account age.

## 3. Hall of Fame
Recognize:
- Game of the Year winners.
- Game of the Semester winners.
- Game Jam winners.
- Outstanding developers and teams.
- Best capstone projects.
- Notable alumni achievements.

Each entry should include category, award period, recipient/project, description or citation, and publication status.

## 4. Historical integrity
- Avoid deleting old award records when categories change.
- Preserve original award names and dates.
- Correct factual errors through audited edits.
- Mark unavailable external links without erasing the historical record.
- Keep archive browsing filterable by academic year and graduating batch.
