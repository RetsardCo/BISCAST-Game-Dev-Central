# Project Overview

## 1. Product statement
BISCAST Game Dev Central is a public-facing digital showcase and archive for games and related creative work produced by BISCAST BSEMC Game Development students and alumni.

It is intended to:
- Make student-developed games discoverable.
- Give students a moderated way to submit and present projects.
- Preserve game-development work across academic years.
- Recognize strong projects, teams, and developers.
- Provide a durable archive for capstone projects and alumni contributions.

## 2. Guiding principles
1. **Student work first:** give projects and their creators clear attribution.
2. **Curated publication:** submissions are reviewed before becoming public.
3. **Low operating cost:** use managed free tiers initially; avoid hosting game builds and videos.
4. **Security by design:** enforce permissions in the database, not only in the UI.
5. **Long-term preservation:** graduating students' published contributions remain archived.
6. **Incremental delivery:** release a useful showcase before adding complex community features.

## 3. Primary audiences
- Public visitors: browse published games, capstones, announcements, and awards.
- Verified students: maintain profiles, submit projects, and participate in eligible votes.
- Alumni: retain a public portfolio and archived contributions.
- Moderators: review content and manage community material.
- Super Admins: manage roles, configuration, and privileged operations.

## 4. Scope
### In scope
- Public game library and game detail pages.
- Search, genre/category filters, academic-year and semester archives.
- Developer profiles and team credits.
- Student authentication using an approved Astean-email verification approach.
- Game submission and moderation.
- Announcements, competitions, and game jams.
- Voting, rankings, and awards.
- Dedicated capstone showcase.
- Alumni archive and Hall of Fame.
- Administrative dashboard.
- Responsive design, accessibility, security, testing, and deployment.

### Out of scope for initial releases
- Hosting downloadable game binaries.
- Building a game engine or game launcher.
- Custom video streaming infrastructure.
- Payments, marketplace transactions, or revenue sharing.
- Unmoderated public uploads.
- Public comments or direct messaging unless separately approved.
- Native mobile applications.

## 5. Success measures
Track measurable indicators after launch:
- Number of approved games and capstone entries.
- Number of represented academic years.
- Number of verified student and alumni profiles.
- Submission review turnaround time.
- Percentage of submissions with complete attribution and working links.
- Availability and error rate of the public site.
- Voting integrity incidents (target: zero confirmed duplicate/unauthorized votes).

Do not publish fabricated counts. Show empty states until real data exists.
